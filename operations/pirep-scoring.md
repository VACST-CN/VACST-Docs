# VACST PIREP 量化评分标准表

> 标准版本：2.0
> 规则版本：PIREP Scoring Rule Set v2
> 分值范围：0-100 分

v2 的评分、异常时间和阶段归属以服务端保存的遥测为准。客户端上报的阶段、事件标签和异常时间仅作为输入证据，服务端会按 `capturedAt` 排序并重新校正阶段后再评分。

## 1. 总体评分公式

### 1.1 阶段分

```text
普通阶段分 = clamp(100 - 阶段内全部扣分, 0, 100)
着陆阶段分 = clamp(着陆率基础分 - 着陆阶段附加扣分, 0, 100)
缺失阶段分 = 0
```

### 1.2 总分

```text
PIREP 总分 = clamp(
  Σ(阶段分 × 阶段权重 ÷ 100) - 全局 penalty 扣分,
  0,
  100
)
```

### 1.3 最低阶段分

```text
最低阶段分 = 所有存在有效遥测阶段中的最低分
```

完全没有有效遥测时，最低阶段分为 0。

### 2.1 服务端阶段重建与边界

- 阶段代码会先统一为 `pre_departure`、`pushback`、`taxi_out`、`takeoff`、`climb`、`cruise`、`descent`、`approach`、`landing`、`taxi_in`、`arrival`。
- 以 `onGround` 的离地和接地变化校正起飞、着陆边界。起飞滑跑（地速超过滑行限制但尚未离地）计入 `takeoff`，不计入 `taxi_out` 的滑行超速。
- 接地后的着陆滑跑仍计入 `landing`；地速降至滑行范围后才计入 `taxi_in`，因此着陆滑跑不计入滑行入超速。
- 进近阶段在低高度证据不足时使用该阶段全部采样；有 `AGL <= 1,500 ft` 证据时只使用低高度采样检查进近下降率、坡度和起落架。
- 发生短暂爬升复飞时，只有持续至少 3 秒且相邻证据间隔不超过 30 秒，才会把终端进近重新校正为爬升。

## 3. 严重级别标准

| 级别 | 是否扣分 | 是否阻止自动通过 | 标准含义 |
|---|---:|---:|---|
| `penalty` | 是 | 分数或阶段分低于门槛时阻止 | 一般量化偏差 |
| `review` | 是 | 是 | 必须人工审核 |
| `block` | 是 | 是 | 严重异常，必须人工审核 |

规则级别为 `review` 或 `block` 时，即使该规则扣分为 0，也不得自动通过。

### 3.1 持续证据与违规时间（v2）

- `crash` 和 `slew` 必须连续检测至少 3 秒才成立；相邻证据间隔超过 30 秒会重置连续区间，单帧标记不会生成服务端异常事件或评分阻断。
- 下降率异常（下降阶段 `-4,000 ft/min`、进近阶段 `-1,000 ft/min`）必须持续至少 3 秒，且采样间隔不得超过 30 秒。
- 滑行超速必须由相邻超限采样累计至少 5 秒确认；任一相邻间隔超过 30 秒不计入累计时长。
- 违规时间使用实际触发时间：极值规则记录达到极值的采样时间，持续规则记录区间内极值采样时间，事件时间线记录服务端确认时刻。不得使用报告提交时间代替。
- 同一规则在评分结果中按规则代码去重；原始遥测仍完整保存，供人工审核追溯。

## 12. 着陆阶段量化标准

```text
R = abs(landingRate)
```

## 16. 遥测完整度量化标准

有效采样少于 2 条时：

```text
完整度 = 0
```

有效采样不少于 2 条时：

```text
阶段覆盖率 = 有数据阶段数 ÷ 11 × 100
连续性 = clamp(100 - 遥测中断次数 × 20, 0, 100)
完整度 = 阶段覆盖率 × 70% + 连续性 × 30%
```

| 11 | 0 | 100.00 | 100 | 100.00 |
| 10 | 0 | 90.91 | 100 | 93.64 |
| 9 | 0 | 81.82 | 100 | 87.27 |
| 8 | 0 | 72.73 | 100 | 80.91 |
| 11 | 1 | 100.00 | 80 | 94.00 |
| 11 | 2 | 100.00 | 60 | 88.00 |
| 11 | 3 | 100.00 | 40 | 82.00 |

## 17. 数据可信度量化标准

有效采样少于 2 条时：

```text
可信度 = 0
```

有效采样不少于 2 条时：

```text
可信度 = clamp(100 - 各可信度事件扣分之和, 0, 100)
```

| 可信度事件 | 扣分 |
|---|---:|
| 遥测中断 `telemetry_gap` | 15 |
| 位置跳变 `position_jump` | 35 |
| 着陆率不可用 `landing_rate_unavailable` | 30 |

## 22. 评分结果与异常时间线

评分结果同时包含阶段评分、去重后的违规列表和飞行事件时间线。时间线只展示状态变化、阶段变化、离地/接地、设备构型变化和服务端确认的异常；高频 `state_snapshot` 周期快照不会混入关键事件列表。每个异常应关联最近的遥测采样，便于从事件跳转到证据。

报告页面默认显示重点遥测采样：开始/结束、航程 25%/50%/75%、阶段边界、最高高度、最大地速、最大爬升率、最大下降率和异常事件对应采样。需要逐点审计时再切换到完整采样；两种视图使用同一份原始航迹和原序号。
